# Pokite public website

Static marketing site, separate from the private Pokite application. Published
by GitHub Pages from this directory. No agent endpoints, access tokens, analytics
or login forms are included. English and Chinese copy describe only shipped
capabilities; push notifications are explicitly marked as not yet available.

The layout takes inspiration from Rene's spacious editorial style. Illustration,
branding and copy are original to Pokite; no Rene assets or fonts are copied.
The mobile screenshot uses the repository's synthetic demo fixtures.

Preview: `python3 -m http.server 4175 --bind 127.0.0.1 --directory site`.
